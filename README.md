### project 1-Plant Care Assistant
A simple web-based Plant Care Assistant that helps users take better care of their plants. Users can select or enter plant details and receive basic care guidance such as watering, sunlight, and general maintenance tips.

### Project 2 - Student Grade Predictor
A web-based Student Grade Predictor that estimates a student's grade based on their academic performance. The project takes relevant marks or scores as input, processes them using conditional logic, and displays the predicted grade/result.
[Live Demo](https://honnushree045-png.github.io/DecodeLabs-Internship/project2.html)

### Project 3 - AI Movie Recommendation
An interactive movie recommendation website that suggests movies based on the user's preferences. Users can provide choices such as genre, mood, language, or other preferences, and the system uses decision-making logic to recommend suitable movies.
[Live Demo](https://honnushree045-png.github.io/DecodeLabs-Internship/project3.html)
